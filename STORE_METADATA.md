# PlayFun20 Store Metadata

The canonical store-listing source, privacy/data-safety drafts, and content-rating notes for all 20 apps are retained in the PlayFun20 project source package. This repository is the active build/regression workspace. Before production, each listing must be revalidated against the exact monetized binary and real screenshots.

Apps covered: TruthTap, Roast Button, BS Meter, Fake Call Fun, Most Likely Party, DareDrop, Settle It, Screen Crack Prank, VoiceWarp Lite, PrankDeck, AgeGuess Fun, FaceScore Fun, BarkBack, BabbleBack, Spooky Radar, SpinDecide, AskOrb, EscapeCall, TapReflex, and PocketGuard Alarm.

Base v1 policy assumptions: no account, no developer-operated server, no location tracking, no advertising/analytics SDK in regression builds; microphone only for VoiceWarp Lite, BarkBack, and BabbleBack; selected photos processed locally for AgeGuess Fun and FaceScore Fun; sensor readings local-only for Spooky Radar and PocketGuard Alarm. Update privacy/Data Safety before release if AdMob, Play Billing, analytics, cloud processing, or any third-party SDK is added.
