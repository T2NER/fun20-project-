# Google Play readiness checklist

## Already prepared
- targetSdk 36 / compileSdk 36
- Unique application ID for every app
- Android App Bundle build targets
- Original app names and in-app text
- Store metadata/privacy/data-safety materials prepared in the project source package
- Permission minimization
- Entertainment/simulation disclosures for novelty functions
- GitHub Actions regression/build workflow

## Must be completed with your accounts/devices before production
1. Create/secure an upload keystore and sign release AABs.
2. Capture real screenshots from each final app build.
3. Host privacy-policy pages at public URLs and enter them in Play Console.
4. Complete Play Console Data safety and content-rating forms based on exact final binaries.
5. Add AdMob/Play Billing only with real account IDs, then update disclosures.
6. Run internal testing on actual phones.
7. Satisfy any Play closed-test requirement that applies to the developer account.
8. Upload each AAB to its own Play Console listing and resolve pre-launch findings.
