# Monetization plan

The base source intentionally contains no advertising or analytics SDK so regression binaries can be tested with minimal privacy/policy surface.

Recommended rollout after functional testing:
- Free app with restrained banner/native ads on non-interactive screens.
- Optional one-time Remove Ads / Pro product.
- Rewarded ads only for optional bonus content.

Use real AdMob application/ad-unit IDs and Play Billing product IDs before production, and revise privacy/Data safety declarations after adding those SDKs.
